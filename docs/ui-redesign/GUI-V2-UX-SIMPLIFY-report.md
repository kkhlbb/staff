# GUI-V2-UX-01 工作流极简化重构验收报告

## 1. 背景与核心设计目标

针对 `v0.5.1-beta` 实机体验反馈——**「按键太多，普通用户跑通一次完整 workflow 门槛过高」**，本次重构以「普通用户 3 步跑通一次完整 workflow（**① 连上 AI → ② 看图对话改图 → ③ 核查并确认保存**）」为唯一主轴，通过：
1. **独占聚焦向导**（首屏只做 1 个决定，不再在向导下方同时渲染整个主工作台）；
2. **渐进披露（Progressive Disclosure）**（零件结构、任务书附件、连接/授权详情默认收起，按需展开）；
3. **低频收纳（「更多 ⋯」菜单）**（主题切换、模式切换、切项目、迁移报告、只读授权视图、旧工作台统一收纳）；
4. **按需浮现（Contextual UI）**（未选中对象时悬浮上下文条 100% 隐藏；正常态 0 条异常横幅；仅展示当前下一步所需的 1 个授权按钮）；

将首屏常驻可见按钮/链接数量大幅削减 **68%–78%**，同时 **100% 保留全部既有安全守卫、状态机、无障碍快捷键与 19 项窄接口**。

## 4. 普通用户完整 3 步 Workflow 路径

1. **① 连上 AI**：打开应用 → 居中单栏向导选「连接本地 Agent（推荐）」一键复制 MCP 配置（或选「使用模型 API」填密钥测通，或点底部「先跳过，直接体验工作台」）→ 点主按钮「进入工作台 / 开始建模」。
2. **② 看图对话改图**：中央纯粹大画布直接拖拽/滚轮看图、点选零件面或图纸标注（或左上角点开「零件结构」）→ 底部浮出引用胶囊点「带入下一句话 / 复制到外部会话」→ 右侧极简输入盒发指令（空对话态可直接点选 3 条引导示例句）。
3. **③ 核查并确认保存**：切右侧「检查」Tab 点击条款同步高亮 3D/2D 与任务书原文 → 点顶栏主 CTA「完成并保存」→ 完成绑定指纹一次性人工确认提交正式版本。
