# V2.2 审查修正（F1–F6）

审查日期：2026-11-08。分支：`agent/dsh-v2.2`。
本文件只记录本轮审查要求的六项修正、对应测试与证据位置；不改变公式、精度或验收口径。

## F1 历史报告不再重算基线

- 快照新增 `comparison: { baselineResult, diff }`，创建时由同一版引擎同时冻结
  基线结果与 `compareChains` 的完整 Diff（`src/history/snapshots.ts`）。
- `ScenarioCompare` 新增可选 `diff` 属性：传入冻结 Diff 时只展示，不调用
  `compareChains`；工作台实时对比仍按当前输入计算（`src/components/ScenarioCompare.tsx`）。
- `PrintReport` 只把 `snapshot.comparison.diff` 交给组件；旧快照没有该字段时
  明确显示“不补算”，不调用当前引擎（`src/pages/PrintReport.tsx`）。
- 用例：
  - `snapshots.test.ts` → “创建时冻结基线结果与完整对比；报告不需要再调用 compareChains”
  - `PrintReport.test.tsx` → “基线对比只读取快照冻结的 Diff，不按当前引擎重算”
  - `PrintReport.test.tsx` → “旧版快照没有冻结对比结果时不补算，只显示不可用说明”

## F2 合法缺附件可导出、可恢复

- `manifest.json` 新增 `missingAttachments`，逐条声明没有 Blob 字节的 revision；
  导出不伪造附件、不删除 revision（`src/backup/projectBundle.ts`）。
- 恢复只接受 manifest 已声明且 revision 元数据一致的缺失；恢复后 revision 保留，
  Blob 不存在，附件保持不可用（`src/backup/restore.ts`）。
- 用例：`projectBundle.test.ts` → “JSON 导入产生的合法缺附件项目可以完整备份，
  并在空库恢复为附件不可用”。

## F3 快照结构与一致性校验

- `restore.ts` 为 review / findings / pending / calculation / groups / byStatus、
  sourceManifest 的 documents / revisions / bindings、result、comparison 建立完整
  Zod 结构校验，并做必要一致性校验（草稿↔定义、结果算术关系、审查计数/待办/
  分组、来源清单与版本元数据、基线与对比前后值）。
- 坏包在 `parseBackup` 阶段、打开写事务之前拒绝。
- 夹具与用例：`invalid-snapshot-review`、`invalid-snapshot-binding`、
  `invalid-snapshot-documents`、`invalid-snapshot-inconsistent`，均断言
  `invalid_record` 且零写入。

## F4 创建快照与删除项目竞态

- 最终写事务纳入 `projects` store，并在事务内复查项目仍存在；项目已删除时
  不写快照、不写创建事件（`src/history/snapshots.ts`）。
- 用例：`snapshots.test.ts` → “最终写事务前项目被删除时拒绝创建，不留孤儿快照
  和创建事件”（测试注入 `beforeFinalWrite` 复现窗口）。

## F5 解压总量口径一致

- 导出按最终 ZIP 的全部条目（含 `manifest.json`）累计校验；与恢复端
  `zip.ts` 的条目累计口径一致（`src/backup/projectBundle.ts`）。
- 用例：`projectBundle.test.ts` → “解压总量按最终 ZIP 全部条目累计，临近上限时
  不会导出成功、恢复失败”（测试注入 `maxUncompressedBytes`）。

## F6 跨项目 Blob 引用

- 恢复时要求 Blob 的 `projectId` 与 revision 的项目作用域一致；不一致按
  `missing_reference` 拒绝（`src/backup/restore.ts`）。
- 夹具与用例：`invalid-cross-project-blob.cunlian.zip`。

## 顺带项

- 报告每页页脚：`第 N 页 / 共 M 页 · 快照 <短 ID>`，使用 `@page` 的
  `@bottom-center` 页边距盒；短 ID 过滤为字母数字，避免 CSS 注入
  （`src/pages/PrintReport.tsx`、`src/pages/PrintReport.css`、`src/history/snapshotId.ts`）。
- 路径穿越变体拆成独立夹具：relative / absolute / backslash / encoded；每个断言
  具体错误码，不再使用泛化的 `invalid_zip`。
- 写入中途失败回滚用例：`projectBundle.test.ts` → “写入中途失败时整体回滚，
  所有 store 保持空库”。
- 历史事件逐条深比较：空库恢复用例中按 id 排序后 `toEqual` 原始事件。
