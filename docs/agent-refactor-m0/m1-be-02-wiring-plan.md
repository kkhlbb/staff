# M1-BE-02 双入口接线派发计划

当前桌面主进程通过 `m1AuthorizationChannels.ts`、`m1LocalAuthority.ts` 和 `m1ReadChannels.ts` 提供原生只读授权、上下文与事件拉取。授权窗口绑定到经 `m1FileBindings.ts` 验证的项目文件版本。远端对等方解析仍返回空结果，订阅和取消当前返回能力未开放。内部服务已有写入、日志及订阅生命周期原语。

先派发 BE-02C，冻结主进程内部调用端口、授权范围和错误语义。端口冻结后，A、B、D 可各自开发，最终由集成负责人统一合并 `desktop/main/index.ts`、共享桌面契约和能力开关。以下路径均相对仓库根目录。

## BE-02C 唯一写入方与草稿 stageChange

- 在 `desktop/main/project-agent/m1LocalAuthority.ts` 扩展可信调用主体及项目写授权。沿用 `m1FileBindings.ts` 和同一绑定下的服务实例。接管由可信客户端确认，写入方身份及权限由主进程解析。项目切换、撤权、导航和外部文件替换清理相应凭据。
- 在 `desktop/main/project-agent/m1InternalService.ts` 与 `guards.ts` 基础上提供共享 `stageChange` 端口。核对 `desktop/shared/project-agent/m1-entry-1933.ts` 的候选请求及结果与内部服务形状。由同一事务验证 writer token、epoch、授权、基准版本、预期草稿版本和幂等键，然后保存草稿、日志和回执。对当前仅支持的类型化隔套创建／续接定义边界，缺项沿用 `m1TaskMachine.ts` 的提问续接，越界返回明确错误。
- 交付端口与并发回归。两个入口竞争只有一个写入方。接管后旧的排队请求失败。重发同一逻辑请求只生成一份回执与草稿，复用键但修改有效负载返回冲突。基准过期时无部分写入，进程重启恢复草稿及日志并重新授权。

## BE-02A 安装包外部 MCP 桥接与唤起

- 保留 `mcp/server.mjs` 既有五个工具，新增独立随包 stdio 桥接入口与客户端配置。在 `forge.config.ts` 明确桥接资源分发及可执行入口，使用绝对路径参数调用已安装应用，覆盖含空格的路径。
- 向桌面主进程连接当前用户专属的本地端点，定义启动、就绪、超时和重连协议。主进程校验本地对等方，并以可信客户端操作将其授权限定在选定的文件绑定。桥接把项目操作交给 C 的端口，从 D 取得日志及续接数据。
- 交付安装包和可运行配置。在目标 Mac 的交互 GUI 会话、无 Node/npm 开发环境下验证冷启动、热启动、拒绝授权和重复请求。记录安装位置及带空格路径、客户端、macOS 和架构，验证旧工具调用及返回兼容。

## BE-02B 模型 API 工具往返

- 复用 `desktop/main/realModelRuntime.ts`、`openaiCompatibleAdapter.ts` 和钥匙串配置为每个任务创建适配器。把模型 tool call 经白名单和共享 schema 校验后交给 C 的端口，将带对应 tool call ID 的结构化结果回传模型。主进程保存工具往返与步骤关联，复用 `desktop/main/project-agent/m1TaskMachine.ts` 的澄清和续接语义。
- 工具参数只接受受支持的操作、值与已授权来源引用。绑定由可信上下文提供，授权、接管和提交来自可信客户端操作。任务取消或切换后抑制迟到结果，日志保留步骤和错误信息并排除密钥。
- 交付可重放的模型工具往返用例和一个真实 API 记录。覆盖缺项提问后续接、工具输入无效、供应商中断和取消。对同一受支持输入与 A 比较规范化草稿、来源及活动日志。

## BE-02D 订阅与断线续接

- 接通 `desktop/main/project-agent/m1ReadChannels.ts`、`m1InternalService.ts`、preload 及外部端口。绑定订阅到授权代际、调用方和文件身份，沿用 `acceptEntryDelivery`、`routeEntryPage` 的页校验与事件分流。主进程从已持久化日志投递，订阅建立即从声明游标补齐，再跟进新增事件。取消、撤权和导航后停止投递，并在异步响应前复核授权。
- 重连先取当前上下文及快照游标，再查询后续事件。按序消费并去重，游标过期或序列缺口时重新取快照。普通保存保留同一经验证的绑定，保存中短暂授权失败可等保存完成再读。另存、副本和外部替换重新授权并重新取游标。进程重启后重新授权，再读同一文件绑定的日志。
- 交付竞态回归及真实窗口记录。覆盖补读与推送重叠、迟到推送、断线跨多页续接、旧代际拒收、保存续接及关闭重开。

## 集成门槛与待确认项

C 端口完成后接入 A、B、D，分别按生产接线及验证结果开启对应能力。干净 Mac 上用两个入口从等价输入生成同一类受支持草稿，竞争写入、断线重发与重开后核对草稿及日志，保留可重放记录。当前内部草稿只覆盖隔套语义，安装板几何、出图和多维检查列入 M2，正式保存及迁移列入 M3。目标 macOS/架构、首个外部 MCP 客户端和真实 API 服务由集成前确认。本卡只做计划，未验证这些生产链路。真实 BrowserWindow 授权、取消、撤权和保存续接仍需要交互 GUI 记录。
