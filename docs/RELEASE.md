# 发布说明 · 寸链 V3.6.0-alpha（macOS / Apple 芯片）

本文件说明**未签名产物**的获取、校验与安装方式，以及这一版能做与不能做的事。签名与公证**未做**，这是有意的：项目按开源自用发布，不为分发购买 Apple Developer 账号。

## 1 产物与校验

| 文件 | 大小 | SHA-256 |
|---|---|---|
| `寸链-v3.6.0-alpha-macOS-arm64.zip` | 121,142,329 字节 | `b5c390e8b4f5fea406259b38d47262228fef0c9d90dca4d4e3fe7c631aa55e40` |

下载后先校验，再解压：

```bash
shasum -a 256 寸链-v3.6.0-alpha-macOS-arm64.zip
# 必须与上表一致；不一致就别用
```

## 2 安装（首次打开会被 Gatekeeper 拦，属预期）

未签名未公证的 macOS 应用，从网络下载后首次打开会被系统拦下。放行一次即可：

1. Finder 里**右键** `寸链.app` → **打开** → 再点一次「打开」；或
2. 系统设置 → 隐私与安全性 → 底部找到拦截提示 → **仍要打开**；或
3. 终端：

```bash
xattr -dr com.apple.quarantine /Applications/寸链.app
```

**自己从源码构建的产物不需要这一步。**

## 3 从源码构建（不需要开发者账号）

```bash
npm install
npm run package:desktop -- --arch=arm64
# 产物：out/寸链-darwin-arm64/寸链.app
```

## 4 这一版能做什么

- 打开/保存/另存为 `.cunlian`（项目、来源附件、版本、事件、分析快照都在一个文件里）
- 隔套三参数驱动 A4 横向工程图，矢量 PDF / SVG 导出（真文本与矢量路径，不是截图）
- 参数绑定组成环、改图联动、基准失效屏障、一次原子提交
- 任务书条款：绑定 PDF 选区 + 原文 + 闭区间上下限，作为唯一判定依据；原项目目标独立保存
- 条款版本历史：每个版本可定位回它当时的 PDF 版本与选区
- **任务书 PDF 提取（本版新增）**：抽环结构、上下偏差、目标区间与公式 → 生成**待人工确认**候选；每条候选强制带出处（版本/页/选区/原文片段）

## 5 这一版不能做什么（重要）

- **只处理带文本层的 PDF**：不做 OCR、不做 DOCX/Word/Excel、不做图片识别、不联网识别
- **样本覆盖极窄**：提取功能**只验证过 1 份自造样例**（`TB-2026-1110`，2 页）与 3 份自造坏样例。真实外部任务书、复杂表格、分栏排版、特殊字体编码**均未验证**。遇到抽不出或自相矛盾时，功能会**阻塞并说明原因**，这是设计行为，不是故障
- 只支持一种表格列序：`位号 / 名称 / 基本尺寸 / 上偏差 / 下偏差`
- 公式只解析线性加减
- 定位高亮仅在 rotate 0、页原点 (0,0) 的情形下验证过；旋转 90/270、非零/负原点未验证
- 提取决定随项目文件保存；**未保存就退出会丢**
- 确认身份是本地操作名 `local-operator`，不是实名批准
- 不做 STEP/DXF 出图、不做多尺寸链联合求解、不做自动读图

## 6 数据与隐私

- 计算、渲染、PDF 生成全部在本机完成，**不发网络请求**
- 项目文件是你指定的 `.cunlian`；应用目录只存最近项目索引、界面偏好与恢复草稿
